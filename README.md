**Задание:** найти все числа Армстронга в заданном диапазоне.

## <a name="lab-05"></a> Лаб. 5 — Массивы структур. Сортировки

> Отчёт хранится в `lab-05/report.pdf`

**Задание (вариант №195):** работа с массивом структур «Запись в журнале событий» (лог).

**Структура данных:**
```c
typedef struct {
    int  id;              // идентификатор
    int  priority;        // уровень: debug/info/warn/error/fatal
    char message[256];    // текст события
} Log;
```

**Реализованные алгоритмы сортировки:**

- **Shaker sort** (шейкерная) — двунаправленный вариант пузырьковой сортировки
- **Double selection sort** — двусторонняя сортировка выбором (одновременно ищет min и max)
- **qsort** — стандартная библиотечная, используется для сравнения производительности

Сортировка поддерживает выбор поля (`id` или `priority`) и направления (возр./убыв.).

**Ввод/вывод:** текстовые и бинарные файлы, stdin. Аргументы командной строки через `getopt`.

**График производительности:** зависимость времени сортировки от размера массива (1K – 1M элементов) показывает, что qsort значительно опережает оба ручных алгоритма на больших данных.

Утечки памяти проверены с помощью **Valgrind** — `0 errors`.

**Файлы:**
```

├── sort.c       ← алгоритмы сортировки
├── rw.c         ← чтение/запись (текст и бинарный формат)
```

## <a name="lab-06"></a> Лаб. 6 — Структуры данных на основе списков

> Отчёт хранится в `lab-06/report.pdf`

**Задание (вариант №2):** удалить из строки все символы до первой точки и после последней точки с запятой. Строка хранится в виде **односвязного списка** символов.

**Структура узла:**
```c
typedef struct Node {
    char ch;
    struct Node *next;
} Node;
```

**Реализованные функции:**

- `push(&head, ch)` — добавление символа в конец списка
- `printlist(head)` — вывод всего списка
- `process(&head)` — обрезка: ищет первую `.` и последнюю `;`, освобождает лишние узлы

**Пример работы:**
```
Input:  123qwe..asdzxc;zxczxc
Output: ..asdzxc;
```

Ввод через `getchar()` до `EOF`. Утечки памяти проверены с помощью **Valgrind** — `0 errors`.
